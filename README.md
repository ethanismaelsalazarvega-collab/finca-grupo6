## 4. Estructura del proyecto

- `pom.xml`: configuración del proyecto Maven y sus dependencias.
- `src/main/java/ec/edu/uagraria/finca/Parcela.java`: clase principal que representa una parcela.
- `src/test/java/ec/edu/uagraria/finca/ParcelaTest.java`: pruebas de la clase Parcela.
- `src/test/java/ec/edu/uagraria/finca/ParcelaSalazarTest.java`: prueba individual de Salazar.

## 5. Requisitos previos

- Java compatible con la configuración del proyecto.
- Apache Maven disponible desde IntelliJ IDEA.
- IntelliJ IDEA.
- Git para la gestión de versiones.

## 6. Ejecución de las pruebas

1. Abrir el proyecto en IntelliJ IDEA.
2. Cargar el proyecto Maven desde `pom.xml`.
3. Abrir la ventana Maven.
4. Desplegar `Lifecycle`.
5. Ejecutar el objetivo `test`.
6. Comprobar que el resultado sea `BUILD SUCCESS`.

## 7. Control de versiones

El código fuente se administra mediante Git y se publica en el repositorio compartido de GitHub.

Para consultar el historial de cambios, ejecutar:

```bash
git log --oneline
```

Para comprobar el estado del repositorio, ejecutar:

```bash
git status
```
